Playwright Runner

Run and manage Playwright end-to-end tests from the Zed editor.

A community Zed extension that mirrors the Playwright VS Code extension through the surfaces Zed gives extensions. Work in progress.

Install

playwright-runner : install
  1. In Zed, open zed: extensions and search for Playwright Runner.
  2. Turn on code lenses in your Zed settings: "code_lens": "on".
  3. Open a project with @playwright/test 1.38 or newer, trust the folder, and click ▶ Run test above any test.

Requirements

requirements
Zed 1.23 or newer, Node.js 22 or newer, @playwright/test 1.38 or newer with browsers installed.

Capabilities

01

Run tests

Run the test, describe block or file under the cursor, re-run the last run.

02

Projects

Pick the Playwright projects (browsers) a run uses, remembered per config.

03

Step labels and run output

See the executing step and per-step durations inline, open the full output in a tab.

04

Trace viewer

Record a trace for every run and open it in Playwright's trace viewer.

05

Show browser

Watch tests in a visible browser that stays open between runs.

06

Discovery consent

Nothing runs in a folder until you trust it.
