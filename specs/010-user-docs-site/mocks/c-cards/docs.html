Run tests

Playwright Runner runs the Playwright installed in your workspace. Results arrive as a progress indicator, a pass or fail notification, an error marker on each failing line, and the full output in a tab.

From the editor

ActionHow
Run the test under the cursorctrl-. then Playwright: Run test at cursor, or click the ▶ Run test lens
Run a whole describecursor on the test.describe line, same action, or ▶ Run describe
Run the whole filectrl-. then Playwright: Run file
Repeat the last runctrl-. anywhere in the workspace, Playwright: Re-run last

What you get back

  • A progress indicator while the run is in progress; starting another run cancels it.
  • A notification such as "1 passed, 0 failed, 0 skipped (0.4s)"; the time is Playwright's own measurement.
  • An error marker on the failing line until you edit the file or run again. With two or more projects, each failing project gets its own marker and the message starts with the project in brackets, for example [mobile] adds numbers: ....

Good to know

  • Runs use the file on disk. With unsaved changes you get a warning and the saved version runs.
  • With several configuration files, the one nearest to the test file is used.
  • Playwright below 1.38 produces a single warning and disables running.
